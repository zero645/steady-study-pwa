# 稳步学习

面向 2027 山东专升本的手机优先每日学习执行器。当前以山东省 2026
公共基础课考试要求作为临时基线，等 2027 官方要求发布后再做差异更新。

在线使用：<https://zero645.github.io/steady-study-pwa/>

Android 安装：使用 Chrome 打开在线地址，点击右上角菜单，选择“安装应用”
或“添加到主屏幕”。首次成功打开后，应用外壳可离线使用；网上搜索学习资料仍需联网。

## 当前能力

- 保底、正常、充足和五分钟急救模式
- 每次只显示一个知识点、搜索词和两条完成标准
- 英语每日固定，高数、计算机和语文按真实进度轮换
- 首周 12 个知识点内置 5 题小测和答案解释
- 其余知识点支持记录 5 道外部练习的正确数
- 小测成绩自动决定 1、3、7、14 天复习
- 完整四科知识地图、到期复习、最近七天启动记录
- Android 可安装 PWA、离线应用外壳、学习记录导入导出
- 旧版 `stepwise-study-planner-v2` 进度迁移

## 本地使用

PWA 功能需要通过 HTTP 或 HTTPS 访问：

```powershell
node dev-server.mjs . 4174
```

然后打开 `http://127.0.0.1:4174/app-v3.html`。根目录会自动跳转到新版。

本机地址只用于开发验证。要在 Android 手机上安装，需要把该目录部署到 HTTPS
静态托管，再使用 Chrome 打开并选择“安装应用”或“添加到主屏幕”。

## 数据

学习记录保存在浏览器 `localStorage` 的 `stepwise-study-planner-v3` 项中。
清除浏览器站点数据会同时清除学习记录，操作前应在“进度”页面导出 JSON 备份。

新版排程规则位于 `planner-v3.js`，知识地图位于 `curriculum.js`。使用 Node.js
内置测试模块验证核心逻辑：

```powershell
node planner-v3.test.js
```
